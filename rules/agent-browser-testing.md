# Agent-Browser 공통 검증 기준

> Claude Code agent-browser를 활용한 브라우저 레벨 검증 항목
> 앱 종류와 무관하게 적용 가능한 공통 기준만 정의

---

## 1. 페이지 레벨

| 항목 | 판단 기준 |
|------|----------|
| **정상 렌더링** | 빈 화면, 에러 페이지, 500/404가 아닌지 |
| **콘솔 에러 없음** | JS runtime error 0건 |
| **핵심 레이아웃 존재** | Header, Footer, 메인 콘텐츠 영역이 렌더링되었는지 |

## 2. 인터랙션 레벨

| 항목 | 판단 기준 |
|------|----------|
| **네비게이션 동작** | 주요 링크 클릭 시 올바른 페이지로 이동 |
| **버튼 반응** | CTA 버튼 클릭 시 기대 동작 발생 (모달, 드로어, 페이지 전환 등) |
| **폼 입력 가능** | input/textarea에 텍스트 입력이 정상 동작 |

## 3. 상태 레벨

| 항목 | 판단 기준 |
|------|----------|
| **로딩 → 데이터 표시** | 로딩 스피너 후 실제 콘텐츠가 렌더링되는지 |
| **빈 상태 처리** | 데이터 0건일 때 empty state UI가 표시되는지 |
| **에러 상태 처리** | API 실패 시 에러 메시지가 사용자에게 보이는지 |
